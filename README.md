## 1️⃣ Project Overview

This project demonstrates the development of a **fully functional, responsive, and compliant portfolio website**.  
It showcases web design and development best practices using **HTML5, CSS3, and JavaScript* to meet industry standards.

The website consists of:
- **Home Page** – Introduces the portfolio and includes a navigation, a hero section, a small portfolio section, and text logo on the nav bar.  
- **About Page** – Displays my profile, technical skills and competencies, and my career goals.  
- **Contact Page** – Includes a working contact form using HTML.

## 2️⃣ Objectives

- Apply modern web technologies (HTML, CSS, JS).  
- Demonstrate responsive design principles for mobile and desktop.  
- Implement clean and accessible UI elements.  
- Use JavaScript for interactivity and theme control.

## 4️⃣ Design & Structure

- **Color Scheme:** Light/dark mode using CSS variables.  
- **Typography:** "Poppins" system font for modern readability.  
- **Layout:** Flexbox and media queries ensure responsive layouts.  
- **Consistency:** Reused header/footer across all pages with working navigation and hover states.  
- **Interactivity:**  
  - Theme toggle (manual switch).    
  - Smooth page fade and scroll reveal effects using css + js.
